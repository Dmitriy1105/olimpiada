# Локальный отчёт — «Освоение Марса», агент v1

## Реализовано

- Интерактивный протокол v3.
- Точное fixed-point представление `R0`, `a`, `b` и запасов.
- Восстановление роботов по заявкам всех игроков.
- Оценка предельного дохода по клеткам.
- Оценка территориального расширения и риска конкуренции.
- Вывод только заявок; пустые строки соперников обрабатываются как пропуски.

## Проверки

| Проверка | Результат |
|---|---:|
| Компиляция `solution.py` | PASS |
| Истории self-play, точное воспроизведение | 10/10 PASS |
| Легальность собственных заявок на открытых картах | 10/10 PASS |
| Интерактивный протокол на тестах 01 и 10 | PASS |
| Лишние строки stdout после последнего хода | отсутствуют |
| Использование сторонних библиотек | нет |

Истории проверялись по каждому ходу: стоимость заявок списывалась до начисления дохода, новые роботы добавлялись одновременно, а доход рассчитывался по суммарному числу роботов в каждой клетке. Все рассчитанные запасы совпали с записями.

## Производительность

Локальный запуск выполнен в среде Python 3.13.5. Синтаксис решения совместим с Python 3.11; целевая проверка Python 3.11 должна выполняться CI.

На десяти открытых картах измеренное время `choose_request()` было существенно меньше секунды на ход. Дополнительный синтетический стресс-тест на поле 100x1, 100 ходов и низком `b=0.001` также завершился без превышения локальных лимитов.

## Диагностический replay

`benchmark_replay.py` повторяет записанные заявки игрока 1 из self-play историй, хотя соперник в действительности должен был бы адаптироваться к нашим изменённым действиям. В нескольких партиях за счёт изменения нашей экономики исторический соперник не мог оплатить прежнюю заявку; такие заявки были обрезаны.
