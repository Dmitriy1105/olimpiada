# Локальный отчёт — «Освоение Марса», агент v2

## 1. Изменения алгоритма

- Точная fixed-point арифметика сохранена.
- Для каждого доступного размещения считается предельный доход за оставшиеся ходы минус стоимость робота.
- Первый робот в новой клетке дополнительно оценивается по числу ещё не открытых соседей.
- Если экономические оценки равны, приоритет получает общая граница доступности с ближайшим соперником; следующий критерий — число свободных соседей.
- Распределение роботов выполняется через max-heap. На каждой итерации пересчитывается только следующая предельная выгода выбранной клетки.

## 4. Как интерпретировать результат

Это не официальный score и не полноценный турнирный benchmark. Истории — записи self-play, а соперник в replay не меняет свою стратегию в ответ на наши новые действия. Поэтому локальное улучшение на 0.42% — лишь сигнал, что новый tie-break перспективен, но оно не гарантирует роста официального балла.
