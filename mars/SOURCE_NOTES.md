# SOURCE_NOTES — пакет mars-public-v13

Эти заметки извлечены из загруженных `statement.md`, `protocol.md`, `starter.py`, `tests/` и `histories/`.

## Механика

- Поле прямоугольное, координаты `(x, y)`, соседство 4-связное.
- Препятствия и станции заблокированы для размещения.
- Клетка доступна игроку, если она соседствует с его станцией или клеткой, где у него уже есть робот.
- Новые роботы открывают соседние клетки только со следующего хода.
- Все заявки выбираются одновременно и независимо.
- Стоимость одного робота — 1 единица ресурса.
- После установки всех заявок доход игрока в клетке равен `max(0, x * (a - b * X))`, где `x` — его роботы, `X` — суммарные роботы всех игроков в клетке.
- Неизрасходованный ресурс сохраняется.
- После последнего хода доход начисляется по тем же правилам.

## Интерактивный протокол

Начальный блок: `W H`, `N`, `T`, `R0`, `a b`, `K`, затем `K` координат препятствий и `N` координат станций.

Каждый ход:
1. Участник печатает одну строку троек `x y value` (пустая строка — пропуск) и делает flush.
2. Читает ровно `N-1` строк заявок соперников в порядке номеров.
3. Читает строку запасов `R_i(t+1)` всех игроков.

После собственного хода `T` участник всё равно читает заявки соперников и итоговые запасы, затем завершает работу без дополнительного stdout.

## Открытые данные

- `tests/01`–`tests/10` содержат карты и в последней строке ID стратегии-бота.
- `histories/01.txt`–`histories/10.txt` содержат по три строки на ход: заявка игрока 0, заявка игрока 1, затем запасы.
- ID стратегий в открытых тестах: `0,0,1,1,2,2,3,3,4,4`.

## Несовпадение формулы оценки

В загруженном `statement.md` указано `Q = sum(R_k / T_k)` и `S = 10 Q / B`.

На скриншотах страницы задачи, переданных в чат, указано другое оценивание: `s_k = min(1, N_k R_k / U_k)`, усреднение по 60 картам и максимум 12 баллов.

Это расхождение не меняет механику игры и интерактивный формат, на которых основан агент, но его нужно проверить по актуальной странице соревнования до финальной отправки.
