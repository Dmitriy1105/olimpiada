# Освоение Марса — агент v2

Интерактивное решение для Python 3.11, протокол v3.

## Файлы

- `solution.py` — агент для отправки в проверяющую систему.
- `starter.py` — исходный шаблон из пакета участника.
- `simulate.py` — точный симулятор и проверка десяти историй.
- `test_solution.py` — проверки легальности, синхронизации состояния и интерактивного протокола.
- `benchmark_replay.py` — диагностический replay исторических действий соперника.
- `tests/` и `histories/` — десять открытых карт и десять историй.
- `SOURCE_NOTES.md` — извлечённые правила и замечания к версии условия.

## Что изменилось в v2

1. Доход каждого следующего робота оценивается по точному предельному приросту за все оставшиеся ходы.
2. Первый робот в новой клетке получает небольшой бонус за открытие новых соседних клеток.
3. При равной экономической выгоде приоритет получает клетка общей границы доступности с соперником. Это помогает раньше занимать важный фронтир.
4. Распределение бюджета реализовано через max-heap: после установки робота пересчитывается только следующая предельная выгода этой клетки.
5. Запасы, параметры дохода и доходы представлены целыми числами в точном десятичном масштабе.

## Запуск

```bash
python3.11 mars/solution.py
python -m unittest -v mars.test_solution
python mars/simulate.py
python mars/benchmark_replay.py
```

Сторонние библиотеки не требуются.

## Важное ограничение оценки

Локальный replay использует записанные заявки соперника и при изменении состояния обрезает историческую заявку, если она перестаёт помещаться в его текущий бюджет. Это полезная диагностика, но соперник не адаптируется к новым действиям агента. Поэтому replay не предсказывает официальный балл. Официальный результат v2 ещё нужно получить на платформе.
