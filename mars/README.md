# Освоение Марса — агент v3

Интерактивное решение для **Python 3.11**, протокол v3.

## Файлы

- `solution.py` — решение для отправки в проверяющую систему.
- `starter.py` — исходный шаблон из пакета участника.
- `simulate.py` — точный локальный симулятор и проверка десяти историй.
- `test_solution.py` — проверки легальности заявок и интерактивного протокола.
- `benchmark_replay.py` — диагностический replay исторических действий соперников.
- `tests/` и `histories/` — десять открытых карт и десять self-play историй.
- `SOURCE_NOTES.md` — извлечённые правила и замечания к версии условия.

## Что изменилось относительно v1/v2

v3 основан на более полной модели v1, а не на упрощённой эвристике v2.

- Сохранена оценка вероятности конкуренции за клетки с учётом динамических фронтиров и статического расстояния от станций.
- Сохранена оценка будущей ценности расширения через соседние клетки.
- Вес расширения установлен в 1.25 вместо 1.5.
- Оценка вероятности будущего занятия клетки умножается на 0.89. Это уменьшает избыточный штраф за конкуренцию, который оказался невыгоден на части открытых карт.
- Сохранены точная fixed-point арифметика и heap для предельных доходов.

## Запуск

```bash
python3.11 mars/solution.py
python -m unittest -v mars.test_solution
python mars/simulate.py
python mars/benchmark_replay.py
```

Сторонние библиотеки не требуются.

## Ограничение локального benchmark

Истории — записи self-play. Replay повторяет зафиксированные заявки соперников; если заявка после изменения состояния превышает текущий бюджет соперника, она обрезается. Соперник не адаптирует действия к новому состоянию, поэтому replay — только диагностический тест, а не официальный score и не точная симуляция скрытых стратегий.

Официальный балл v3 можно узнать только после отправки решения на платформу.
