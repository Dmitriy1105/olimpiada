# Mars — Освоение Марса

Первая эвристическая версия агента для задачи «Освоение Марса», протокол v3, Python 3.11.

- `solution.py` — интерактивный агент.
- Точная десятичная арифметика в масштабе, заданном входными параметрами.
- Выбор размещений по предельному приросту дохода на оставшемся горизонте.
- Небольшой эвристический бонус за открытие новых клеток.

Статус: **baseline v1**. Проверена законность заявок и бюджетные ограничения на десяти открытых картах в локальной симуляции против пассивных соперников (3 проверки прошли). Это не является оценкой турнирного качества против пяти скрытых политик. Следующий этап — полноценный симулятор, моделирование соперников и сравнительные эксперименты.
