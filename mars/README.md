# Освоение Марса — агент v4

Экспериментальная адаптивная версия для **Python 3.11**, интерактивный протокол v3.

## Файлы

- `solution.py` — экспериментальный агент v4; именно этот файл отправлять на платформу только после проверки.
- `solution_v1.py` — неизменённая копия проверенной базовой стратегии v1 для сравнительных тестов.
- `starter.py` — исходный шаблон.
- `simulate.py` — точный симулятор и проверка десяти открытых историй.
- `test_solution.py` — легальность заявок, интерактивный протокол и тест модели для четырёх игроков.
- `benchmark_replay.py` — диагностический replay только v4.
- `benchmark_compare.py` — парное сравнение v1 и v4 на одинаковых открытых историях.
- `tests/` и `histories/` — десять открытых карт и записи партий.
- `SOURCE_NOTES.md` — правила, извлечённые из исходного пакета.

## Что изменилось в v4

v4 построен непосредственно на v1. Экономическая модель предельной доходности и оценка расширения сохранены.

Новое:
1. Для каждого соперника отдельно рассчитывается вероятность занятия клетки.
2. Используются его динамическое расстояние от текущей сети и статическое расстояние от станции.
3. Учитывается, доступна ли клетка сопернику уже в текущем ходу.
4. После каждого хода обновляется индивидуальная статистика соперника: доля размещений на нашей текущей границе и EMA доли потраченного бюджета.
5. Для 2–4 игроков рассчитывается математическое ожидание дохода по комбинациям независимых событий занятия клетки (не более (2^3) сценариев).

Статистика обучается онлайн только на заявках, которые уже пришли через интерактивный протокол. В прогнозе текущего хода не используются неизвестные будущие заявки.

## Запуск

Из корня репозитория:

```bash
python3.11 mars/solution.py
python -m unittest -v mars.test_solution
python mars/simulate.py
python mars/benchmark_compare.py
```

Сторонние библиотеки не требуются.

## Ограничения

Парный replay повторяет фиксированные исторические заявки соперника. Они не адаптируются к нашим новым действиям; если историческая заявка не помещается в изменившийся бюджет соперника, она обрезается. Открытые данные содержат только десять двухпользовательских карт. Поэтому benchmark не доказывает преимущество против скрытых карт, других стратегий или 3–4 игроков.

**Результат replay не является официальным баллом.** v4 остаётся экспериментальной до проверки на платформе. Не заменять v1 как лучший подтверждённый вариант, пока официальный результат v4 не станет выше 6,24.
