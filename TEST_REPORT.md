# Локальный отчёт тестирования

Дата: 2026-11-25  
Версия: opponent-specific posterior + scenario rollouts  
Среда исполнения: Python 3.13.5 в локальном контейнере; синтаксис дополнительно проверяется на совместимость с Python 3.11.

## 1. Модульные проверки

Команда: `python -m unittest -v`

| Проверка | Результат |
|---|---|
| Вынужденный пропуск, если ни один предмет не помещается | PASS |
| Допустимость ходов и отсутствие повторного выбора предметов | PASS |
| Симуляции не превышают вместимость рюкзаков | PASS |
| Независимые модели поведения разных соперников | PASS |

Итого: **4/4 PASS**.

## 2. Интеграционная проверка интерактивного протокола

`local_interactor.py` запускает `solution.py` отдельным процессом, передаёт начальные данные, читает каждый ход до отправки ответа соперников и проверяет:

- ровно `T` действий;
- действие `0` только при отсутствии подходящего предмета;
- отсутствие повторного выбора предметов;
- соблюдение вместимости;
- отсутствие лишнего вывода после последнего раунда;
- код завершения `0`.

Максимальный размер: `K=10, N=100, T=20, W=50`.

Результат контрольного запуска (seed=123):

- 20 из 20 ходов получены;
- процесс завершился с кодом 0;
- stderr пустой;
- лишнего stdout нет;
- время полного локального прогона: **2.13 секунды**;
- итог симуляции: собственная масса 46, максимальная масса соперников 50, балл 342.

## 3. Сравнение на синтетических партиях

Условия: 60 фиксированных случайных наборов; `K=5, N=60, T=15, W=35`; соперники используют случайно выбранные стратегии из восьми моделей. Для каждой стратегии использовались те же исходные наборы и те же соперники.

| Наша стратегия | Средний балл | Положительный балл |
|---|---:|---:|
| Текущий агент | **258.78** | **60/60** |
| Максимальная ценность | 113.65 | 32/60 |
| Ценность / масса | 202.72 | 48/60 |
| Ценность / √массы | 203.72 | 46/60 |
| Ценность − 1.5 × масса | 170.10 | 38/60 |
| Минимальная масса | 162.58 | 55/60 |

Это результат **только синтетического симулятора**. Он показывает преимущество текущей эвристики на использованном наборе моделей, но не предсказывает гарантированный балл на скрытых тестах жюри.

## 4. Ограничения текущей проверки

- Официальный интерактор и скрытые тесты недоступны локально.
- Восемь моделей соперников — приближение; реальные соперники могут использовать иные алгоритмы.
- Локальный контейнер использует Python 3.13.5. Код написан с совместимым синтаксисом Python 3.11, но отдельный интерпретатор 3.11 в контейнере не установлен.
- Требуется финальная проверка на платформе соревнования.
