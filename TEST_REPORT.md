## 1. Исправление модели соперников

В предыдущей версии использовались отдельные вероятностные модели для каждого соперника. Это противоречит условию: в рамках одного теста все соперники используют одну общую стратегию.

В версии 2:
- поддерживается один общий posterior по десяти гипотезам стратегии;
- наблюдения всех соперников последовательно обновляют этот общий posterior;
- в каждой симуляции все соперники используют одну и ту же гипотезу;
- при моделировании сохраняется реальный порядок ходов: наш ход, затем соперники по очереди.

Предыдущий benchmark, где каждому сопернику назначалась отдельная стратегия, признан некорректным и не используется для оценки версии 2.

## 3. Сравнительный benchmark

20 синтетических наборов, `K=5, N=60, T=15, W=35`. В каждом тесте одна стратегия выбиралась для всех соперников. Все сравниваемые алгоритмы играли на одинаковых наборах и против одинаковой стратегии соперников.

| Наша стратегия | Средний балл | Положительный балл |
|---|---:|---:|
| Адаптивный агент | **282.10** | **20/20** |
| Максимальная ценность | 110.45 | 10/20 |
| Ценность / масса | 234.85 | 16/20 |
| Ценность / √массы | 215.00 | 14/20 |
| Линейный штраф за массу | 141.95 | 10/20 |
| Минимальная масса | 136.20 | 13/20 |
| Максимальная масса | 12.50 | 4/20 |

Результаты показывают преимущество агента на этом синтетическом наборе из десяти гипотез. Они не доказывают, что скрытая стратегия официального жюри входит в этот набор.

## 4. Что ещё не проверено

- Реальные 32 теста жюри и их скрытая стратегия неизвестны.
- Набор из десяти гипотез — приближение, а не восстановленный код ботов.
- Официальный балл пока не получен.
- Локальные результаты нельзя считать гарантией ненулевого результата на платформе.

## 5. Следующий эксперимент

Отправить именно текущий `solution.py` на платформу и записать:
- итоговый балл;
- статус проверки;
- если доступно — число зачтённых тестов или распределение баллов.

Если версия снова получит 0, потребуется пересмотреть набор гипотез поведения ботов, а не менять протокол ввода-вывода.
