# Задача 7 — «Последний метр»

Экспериментальная версия автопилота для архива участника `last-metre-participant-v2.zip`.

## Файлы

- `make_weights.py` — воспроизводит проверенный кандидат `weights.pt` из исходного `examples/weights.pt`.
- `EXPERIMENTS.md` — методика и результаты парных локальных тестов.
- `weights.pt` — файл для отправки сформирован отдельно; ссылка на него дана в чате.

## Как восстановить weights.pt

Распакуйте архив участника. Скопируйте `make_weights.py` в корень распакованного пакета (рядом с `examples/` и `torch_lander/`) и выполните:

```bash
python make_weights.py
```

Будет создан `weights.pt`. Скрипт использует штатные `torch_lander.load` и `torch_lander.export`.

## Текущий кандидат

От стартовых весов изменены только две строки первого Linear-слоя:
- neuron 0: умножение всех входных весов на 1.6;
- neuron 1: умножение всех входных весов на 1.3.

Все прочие параметры сохранены. Кандидат проходит штатную загрузку: исходные ключи и формы тензоров, float32, все значения конечны.

**Важно:** кандидат показал улучшение на небольшом локальном наборе из 24 эпизодов, но официальный балл на 240 полётах пока не измерен. Не считать улучшение подтверждённым до проверки на платформе.
