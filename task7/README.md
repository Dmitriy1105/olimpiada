# Задача 7 — «Последний метр»

Экспериментальная разработка автопилота для архива участника `last-metre-participant-v2.zip`.

## Текущий локально подтверждённый кандидат

**Модель:** `v3b_wind_p00384`  
**Архитектура:** `42 -> 32 -> 32 -> 9`  
**Изменение:** signed-wind feed-forward, alpha=0.0384; базовая модель v3b.

CELL 11B.10 сравнила v3b, p00192 и p00384 на одинаковых 240 medium-эпизодах (40 на каждое из шести семейств), seed 681204, horizon 800.

| Метрика | v3b | p00384 |
|---|---:|---:|
| Успешные посадки | 152/240 | **169/240** |
| Успешность | 63.33% | **70.42%** |
| Суммарная награда | 22475.215 | **26841.944** |
| Контакты корпуса | 15 | 13 |
| Невалидные посадки | 73 | 58 |

Парная средняя разница награды: +18.1947 на эпизод; семейно-взвешенный bootstrap 95% CI: [11.8034, 24.4092]. Прирост посадок: +17.

Улучшение сосредоточено в crosswind: 2/40 -> 20/40. В approach есть небольшая регрессия: 29/40 -> 28/40. Остальные четыре семейства сохранили число посадок. Подробности и ограничения — в EXPERIMENTS.md.

**Статус:** p00384 — текущий локально подтверждённый чемпион. Пользователь также сообщил об официальном платформенном результате **6.53 балла** (предыдущая попытка — 1.70; прирост +4.83). Этот балл записан со слов пользователя; независимо через платформу не проверялся. Подробности — в EXPERIMENTS.md. Это не официальный балл соревнования и не гарантия результата на скрытых тестах.

## Как сформировать submission artifact (если потребуется восстановить пакет на другой машине)

В рабочей среде участника должны быть доступны папка моделей и установленный пакет `torch_lander`. Скачайте `cell11b11_package_final.py` в ноутбук и выполните:

```python
SCRIPT_PATH = PROJECT_DIR / "cell11b11_package_final.py"
urlretrieve(BASE_URL + "cell11b11_package_final.py", SCRIPT_PATH)

module = runpy.run_path(str(SCRIPT_PATH))
FINAL_DIR = PROJECT_DIR / "submission_p00384"

weights_path, manifest_path, readme_path = module["run_cell11b11"](
    MODELS_DIR,
    FINAL_DIR
)
```

Результат будет создан отдельно:
- `submission_p00384/weights.pt` — файл модели;
- `submission_p00384/manifest.json` — происхождение и SHA-256;
- `submission_p00384/README.txt` — краткий отчёт проверки.

Скрипт требует SHA-256, совпадающий с checkpoint, реально проверенным в CELL 11B.10. Он не перезаписывает исходные веса и отказывается заменять существующий отличающийся `weights.pt`.

**Важно:** бинарный checkpoint остаётся в локальной папке MODELS_DIR пользователя; в GitHub сохранены код упаковки и экспериментальная документация. После запуска CELL 11B.11 сам файл `weights.pt` нужно проверить и использовать из созданной папки.
