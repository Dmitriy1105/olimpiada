# Олимпиада — «Жадные гномы (10)»

Рабочая версия интерактивного решения на Python 3.11+.

## Файлы

- `solution.py` — автономное решение для отправки в проверяющую систему.
- `simulator.py` — локальный симулятор партий против набора жадных стратегий.
- `local_interactor.py` — проверка построчного интерактивного протокола через subprocess.
- `test_solver.py` — модульные проверки.
- `bench.py` — сравнение стратегии с простыми базовыми алгоритмами.
- `TEST_REPORT.md` — результаты текущей локальной серии проверок.

## Запуск проверок

```bash
python -m unittest -v
python local_interactor.py
python bench.py
```

Внешние библиотеки не требуются. Локальные результаты не заменяют проверку на официальном интеракторе.
