# Олимпиада — «Жадные гномы (10)»

Рабочая версия интерактивного решения на **Python 3.11+**.

## Файлы

- `solution.py` — автономное решение для отправки в проверяющую систему.
- `simulator.py` — локальный симулятор партий против восьми моделей жадного выбора.
- `local_interactor.py` — проверка построчного интерактивного протокола через отдельный процесс.
- `test_solver.py` — модульные проверки.
- `bench.py` — сравнение с простыми базовыми стратегиями.
- `TEST_REPORT.md` — результаты локальных тестов и ограничения проверки.

## Протокол

В начале программа читает:
1. `K N T W`;
2. `N` масс предметов;
3. `N` ценностей предметов.

В каждом из `T` раундов:
1. выводит один номер предмета `1..N`, либо `0`, только если ни один оставшийся предмет не помещается;
2. делает `flush`;
3. читает `K-1` действий соперников (`0` — вынужденный пропуск).

После последнего обмена программа завершает работу без дополнительного вывода. В stdout должны находиться только действия.

## Запуск проверок

```bash
python -m unittest -v
python local_interactor.py
python bench.py
```

Внешние библиотеки не требуются.

## Алгоритм

Для каждого соперника независимо поддерживается распределение вероятностей по восьми эвристическим моделям выбора. После наблюдаемого хода обновляется только модель соответствующего соперника. При оценке каждого нашего кандидата моделируются несколько комбинаций поведения соперников и несколько вариантов нашей дальнейшей стратегии.

Это эвристический алгоритм, а не доказанное оптимальное решение. Локальные тесты и синтетический benchmark не заменяют проверку на официальном интеракторе.
