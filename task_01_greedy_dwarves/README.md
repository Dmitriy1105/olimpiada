# Task 1 — Жадные гномы

Интерактивное решение на Python 3.11+.

## Файлы

- solution_v3.py — новая версия с расширенной библиотекой из 46 моделей общей скрытой стратегии.
- local_interactor.py — локальная проверка интерактивного протокола против одной общей стратегии соперников.
- BENCHMARK_REPORT.md — описание локального синтетического benchmark и его ограничений.

## Запуск

Запуск решения: python solution_v3.py
Локальная проверка протокола: python local_interactor.py

## Идея

В рамках одного теста все соперники используют одну и ту же неизвестную стратегию. Решение поддерживает общий posterior по кандидатным стратегиям и обновляет его после каждого наблюдаемого хода любого соперника.

В V3 библиотека гипотез расширена до 46 вариантов: максимальная ценность, степенные отношения ценности к массе, линейные штрафы за массу, смещённые отношения ценности к массе, квадратичные штрафы за массу, минимальная и максимальная масса.

Для оценки нашего текущего действия моделируется оставшаяся партия при каждой гипотезе стратегии соперников и нескольких вариантах нашей дальнейшей политики.

## Важное ограничение

Это эвристическая модель скрытых стратегий. Локальный benchmark использует синтетические стратегии, совпадающие с частью библиотеки гипотез. Он не раскрывает стратегии официального жюри и не гарантирует официальный балл.
