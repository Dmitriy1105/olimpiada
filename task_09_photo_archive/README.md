# Task 9 — Фотоархив

## Результат

Локально сформирован файл `submission.csv` для архива `fragment_album.zip`.

В каждой строке:
- `scene_id` — сцена;
- `crop_id` — фрагмент;
- `object_id` — предсказанная группа физического объекта (нумерация независима внутри каждой сцены).

В интерфейсе соревнования для отправки CSV указать требуемый в условии язык **Make**.

## Метод

Эвристическая instance-level кластеризация по визуальным признакам с жёсткими ограничениями из `distances.csv`.

1. Маска используется для отделения целевого объекта от фона.
2. Для каждого crop извлекаются HSV-гистограмма, HOG-дескриптор, дескриптор силуэта и локальные SIFT-признаки.
3. Для пар-кандидатов вычисляются взаимные SIFT-сопоставления и число геометрически согласованных совпадений после RANSAC.
4. Кандидаты — 60 ближайших соседей по глобальному визуальному дескриптору каждого crop плюс все пары из `distances.csv`.
5. Кластеры строятся через DSU. Каждая пара из `distances.csv` — жёсткое cannot-link ограничение.

Условия принятия визуального ребра:
- не менее 3 взаимных SIFT-сопоставлений;
- и либо не менее 5 геометрических inlier-сопоставлений;
- либо не менее 3 inlier-сопоставлений при глобальном сходстве не ниже 0.55.

## Запуск

Требуется Python 3.11+ и зависимости из `requirements.txt`.

```bash
pip install -r requirements.txt
python solve.py --data /path/to/fragment_album --output submission.csv
```

Архив нужно распаковать так, чтобы каталог `fragment_album` содержал `scene_0001`, `scene_0002` и остальные сцены.

## Ограничения

Эталонная разметка групп в архиве отсутствует, поэтому локально нельзя вычислить официальный pairwise F1. QC подтверждает полноту CSV и соблюдение известных cannot-link ограничений, но не является оценкой F1. Итоговое качество станет известно только после проверки отправленного файла.
